# Podcast-Studio

Remote-Interviews für die Podcasts von Paul Höser (zuerst Biohacking Kompakt) mit 2–3 Personen.

- **Host:** https://phoeser.github.io/podcast-studio/
- **Gast:** bekommt den Link mit `?r=<code>` vom Host

Jede Person wird lokal in voller Qualität aufgenommen (Audio- und Videospur getrennt). Die Teile werden während
des Gesprächs über einen Make-Webhook in den Google-Drive-Ordner „Podcast-Aufnahmen“ hochgeladen.
Hintergrund-Optionen: Original, Weichzeichnen, neutrale Farben, Biohacking Kompakt (Personen-Freistellung im Browser
mit MediaPipe, nichts verlässt den Rechner).
